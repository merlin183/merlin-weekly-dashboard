# 기능과 초기 설정

새 설치는 빈 팀과 빈 업무 데이터로 시작합니다. 화면이 제공되더라도 외부 데이터와 연결되는 기능은 설치자의 연동 설정이 필요합니다.

| 영역 | 제공 기능 | 설치 후 준비 |
| --- | --- | --- |
| 주간 업무 | 주간 보고, 개인 보고, 체크리스트, 요약, 댓글 | 팀원과 보고 항목 등록 |
| 프로젝트와 할 일 | 프로젝트 계층, 칸반, 담당자별 할 일, 메모 | 직접 입력하거나 자신의 Linear 연결 |
| 일정과 회의 | 일정 조회·추가·삭제, 회의록 | Google Calendar 연동은 선택 사항 |
| 근태 | 출퇴근, 월간·연간 상세, 승인 반차 표시, 영업일 누락 확인 | 사용자 입사일과 공휴일 등록 |
| 휴가와 결재 | 휴가 잔액·신청·승인, 결재 문서와 승인선 | 자신의 조직에 맞는 역할과 승인자 설정 |
| 지출 | 지출 기록, 수정, 내보내기와 알림 | 관련 Google Sheets 연동 설정 확인 |
| 지표 | 일별·주별 지표, 추세, 캐시, 요약 | 자신의 분석 DB/API 및 BigQuery 데이터 준비 |
| CS | 별도 로그인 화면, 상담 내역·집계·분류와 주간 요약 | CS 비밀번호 및 자신의 상담·분석 소스 설정 |
| 관리 | 계정과 역할, 팀 설정, 활동 기록, 파일, 내보내기, 백업·복구 | 관리자 계정 초기화와 저장소 정책 설정 |
| 외부 연결 | Slack, Linear, Google 서비스, 선택 AI 기능 | 자신의 자격증명과 자원 ID 설정 |

역할에 따라 화면과 API 접근이 달라집니다. 팀 구성과 승인자는 설치자가 정하며, 특정 조직의 사용자나 승인선은 포함하지 않습니다. 백업 복구와 일괄 수정은 자료를 바꾸므로 먼저 독립된 테스트 설치에서 확인하세요.

## 근태 표시 기준

근태의 날짜 기준은 `Asia/Seoul`입니다. 기본 도착 상태는 09:30을 기준으로 하며, 승인된 오전·오후 반차를 상세 화면에 함께 표시합니다. 반차 표시를 위해 원본 출퇴근 시각이나 승인 기록을 변경하지 않습니다.

상세 화면은 선택월 또는 연간 범위를 조회할 수 있습니다. 영업일 누락 표시는 입사일, 활성 계정, 등록된 공휴일과 최종 승인 휴가를 근거로 보완합니다. 미래 날짜나 불확실한 사용자·휴일 자료를 임의로 결근 처리하지 않습니다. 누락 표시와 원본 출퇴근 기록, 기존 요약 합계는 구분해서 확인하세요.

## 지표의 의미

빈 설치에는 매출·방문자·사용량·상담 데이터가 없습니다. 분석 기능을 사용하려면 [연동 안내](INTEGRATIONS.md)에 따라 자신의 소스와 뷰 또는 API 계약을 준비해야 합니다. 연동이 비어 있거나 실패했을 때 표시되는 빈 값이나 `0`은 실제 사업 지표가 0이라는 증거가 아닙니다.

CS 화면에는 별도의 인증 범위가 있으며 일반 대시보드 로그인과 구분됩니다. AI 요약·분류와 예약 알림은 각 서비스 설정과 데이터 준비가 끝난 뒤 활성화하세요.
