# 개인정보와 데이터

이 저장소는 독립적으로 설치하는 주간 업무 대시보드의 소스입니다. 실제 직원·고객·사업 데이터, 기존 사용자, 운영 데이터베이스와 연동 계정은 제공하지 않습니다. 설치자는 새 데이터베이스와 자신의 계정을 준비합니다.

## 저장되는 자료

| 자료 | 저장 위치와 주의점 |
| --- | --- |
| 계정, 비밀번호 해시, 역할 | 설치자의 PostgreSQL. 비밀번호는 솔트가 포함된 PBKDF2 해시로 저장됩니다. |
| 업무 보고, 프로젝트, 할 일, 메모, 댓글 | 설치자의 PostgreSQL. 본문과 링크에 개인정보가 들어갈 수 있습니다. |
| 출퇴근, 입사일, 휴가, 승인 및 지출 기록 | 설치자의 PostgreSQL. 인사·금융 관련 접근 권한과 보관 기준을 정해야 합니다. |
| 로그인 토큰과 사용자 정보 | 로그인한 브라우저의 로컬 저장소. 공용 기기에서는 로그아웃하고 브라우저 접근을 제한합니다. |
| 업로드, 캐시, 내보내기, 백업 | 서버의 `data/`와 설정한 외부 저장소. 데이터베이스와 함께 보호합니다. |
| 선택 연동의 설정과 자격증명 | 서버 환경변수와 일부 관리자 설정. 관리자 설정 및 DB 백업도 비밀정보로 취급합니다. |

자료가 어디에 저장되는지와 실제 보관 기간은 설치 구성에 따라 달라집니다. 앱에서 한 항목을 삭제해도 별도 백업, 내보내기나 외부 서비스의 사본까지 함께 삭제된다고 가정하지 마세요.

## 외부 전송

기본 설치는 외부 업무 서비스의 계정을 설정하지 않으며 예약 작업을 실행하지 않습니다. 다만 기본 HTML은 Alpine.js를 jsDelivr에서 불러오므로 브라우저가 CDN에 접속합니다. 완전히 분리된 네트워크에서 사용하려면 해당 배포본과 라이선스 고지를 로컬로 제공하도록 수정해야 합니다.

연동을 활성화하면 다음과 같은 자료가 외부로 전달되거나 외부에서 조회될 수 있습니다.

- Slack: 알림, 보고 요약, 오류와 수신자 정보.
- Linear: 프로젝트, 이슈, 담당자와 동기화 정보.
- Google Calendar와 Sheets: 일정, 지출·상담 관련 행과 서비스 계정 정보.
- BigQuery 및 별도 분석 DB/API: 매출, 사용량, 비용, 방문자 등 설치자가 연결한 지표.
- Gemini 및 CS 서비스: 요약 대상 본문, 상담 내용, 분류 결과와 집계 자료.
- Supabase Storage: 업로드한 첨부파일과 저장소 요청.

키를 입력하기 전에 필요한 최소 권한, 전송 대상, 처리 지역, 서비스의 데이터 보관 정책을 확인하세요. AI 기능은 실제 고객·직원의 본문을 전송할 수 있으므로 먼저 가상 데이터로 검증합니다. 연동별 설정은 [연동 안내](INTEGRATIONS.md)를 참고하세요.

## 초기 안전 설정

`BACKGROUND_TASKS_ENABLED=false`, `STORAGE_AUTO_CREATE_BUCKET=false`, `LEGACY_SHARED_LOGIN_ENABLED=false`를 유지합니다. 외부 서비스 키와 자원 ID는 초기 상태에서 비워 둡니다. 백그라운드 작업을 꺼도 사용자가 직접 실행한 연동 요청은 별개이므로, 연동을 사용하지 않으려면 관련 자격증명도 설정하지 않습니다.

Supabase의 서비스 역할 키는 서버에만 둡니다. 앱 테이블은 앱 API를 통해 접근하는 비공개 데이터입니다. Supabase의 공개 Data API에 앱 테이블을 노출하려면 적절한 RLS 정책을 적용하거나, 노출되지 않는 스키마와 제한된 역할 권한을 사용해야 합니다. 서버의 권한 검사만으로 직접 DB/API 접근이 보호되지는 않습니다.

외부 저장소를 사용한다면 파일의 공개 여부와 다운로드 권한을 확인하세요. 자동 버킷 생성을 허용하기 전에 생성 코드와 정책을 검토해야 합니다. 로그인 화면이 있다고 해서 첨부파일 URL까지 비공개라는 뜻은 아닙니다.

## 운영자와 기여자의 확인 항목

- 공개 이슈, 테스트, 화면 캡처에는 가상 이름·이메일·문서만 사용합니다.
- `.env`, 비밀키, 인증서, DB 덤프, 첨부파일, 운영 로그와 `data/`를 커밋하지 않습니다.
- 로그의 오류 본문과 외부 응답에 자격증명·개인정보가 들어가지 않았는지 확인합니다.
- 설치자의 데이터 보관·삭제 절차에 DB, 파일 저장소, 백업, 외부 서비스 사본을 포함합니다.
- 배포 전에 인증, 역할별 조회, 승인 자료 보호와 복구 절차를 자신의 환경에서 확인합니다.

보안 문제는 [보안 정책](../SECURITY.md)의 비공개 경로로 신고합니다.
