# 기능별 화면 · PM 기준

공개본을 PM 계정으로 직접 실행한 화면입니다. 이름·이메일·업무·인사·결재 금액은 가상 예시이며 실제 운영 자료나 인증정보를 포함하지 않습니다.

PM 화면 20장, 관리자 화면 2장, 별도 CS 화면 2장을 구분해 담았습니다.

비용·매출·Linear·Google Calendar·CS 원본은 연결하지 않았습니다. 빈 목록·`0`·미설정 경고는 실제 사업 실적을 뜻하지 않습니다. `DEV` 버튼은 로컬 실행에서만 표시됩니다.

## 화면과 권한 구분

| 구분 | 화면·기능 |
| --- | --- |
| PM 탭에서 보임 | 주간 리포트, 회의록·일정, 비용, 근태/연차, 전자결재, 설정 |
| PM·관리자 공통 관리 | 회사 정보, 승인선, 사용자·권한, 자동화·연동, 백업·내보내기, 감사 로그 |
| 관리자 전용 | 경영 홈 KPI, 연차 총일수 변경, 출퇴근 일괄 삭제, 연차 이력 일괄 반영, PM 단계 대리승인. 최종 승인은 지정된 2차 관리자 승인자가 처리합니다. |
| 별도 CS | 일반 대시보드와 다른 로그인 범위의 CS 지표·상담일지 |

설정 탭을 통째로 관리자 전용으로 분류하지 않습니다. 보이는 버튼과 실제 처리 권한은 구분하며, 아래 캡처는 승인·비밀번호 변경·외부 알림 발송을 실행한 증거가 아닙니다.

### 주간 리포트

오늘 출퇴근·오늘 일정 → 내 이슈·내 결재 → 대표 현황 순서로 보입니다. 대표/관리자용 KPI 화면과 다른 PM 기본 화면입니다.

![PM 기본 화면](screenshots/pm/01-home.jpg)

팀원 보고를 펼쳐 이번 주 진행·다음 주 계획·공유 사항을 작성하고 첨부파일을 관리합니다.

![PM 팀원별 주간 보고](screenshots/pm/02-report.jpg)

주간 체크리스트에서 담당자·항목을 관리하고 확인함·수행 불가 등 점검 상태를 구분합니다.

![PM 주간 체크리스트](screenshots/pm/19-checklist.jpg)

프로젝트 계층과 동기화 영역입니다. Linear를 연결하지 않아 프로젝트 목록은 비어 있습니다.

![PM 프로젝트 계층](screenshots/pm/20-project-hierarchy.jpg)

### 회의록·일정

월간 일정과 담당자 필터를 확인합니다. 외부 캘린더를 연결하기 전이라 일정은 비어 있습니다.

![PM 일정 달력](screenshots/pm/03-calendar.jpg)

회의 유형·주차별로 회의록을 찾고, 내용을 펼쳐 공유 메모와 함께 확인합니다.

![PM 회의록과 공유 메모](screenshots/pm/04-meetings.jpg)

### 비용 관리

월·연도별 비용 목록과 합계를 봅니다. 자신의 Google Sheets를 연결해야 내역이 채워집니다.

![PM 비용 목록](screenshots/pm/05-expenses.jpg)

날짜·담당자·회사·내용·지급 정보·금액을 입력하는 양식입니다. 실제 지급이나 외부 등록은 하지 않았습니다.

![PM 비용 등록 양식](screenshots/pm/06-expense-form.jpg)

### 근태·연차

선택일 출퇴근과 정상·지각 상태, 사용자별 월간 요약을 확인합니다.

![PM 출퇴근과 월간 요약](screenshots/pm/07-attendance.jpg)

월간·연간 범위로 날짜별 출퇴근·근태를 조회합니다. 아래는 `전체(연간)`을 선택한 연간 상세 화면이며 가상 승인 휴가를 포함합니다. 미기록 판단은 입사일·공휴일·승인 휴가가 확인된 범위에 적용됩니다.

![PM 월간·연간 출퇴근 상세](screenshots/pm/08-attendance-detail.jpg)

연차 잔액·사용량·신청 사유와 단계별 승인 상태를 확인합니다. 연차 총일수 변경은 관리자 권한입니다.

![PM 연차 현황](screenshots/pm/09-leave.jpg)

근태 화면의 캘린더 영역입니다. Google Calendar가 미설정되어 현재 일정은 비어 있으며, 가상 승인 휴가가 이 캡처에 표시된다는 의미는 아닙니다.

![PM 근태 캘린더](screenshots/pm/10-hr-calendar.jpg)

### 전자결재

전체·내 요청·받은함과 상태 필터로 요청을 찾습니다. PM에게 배정된 단계만 처리할 수 있습니다.

![PM 전자결재 목록](screenshots/pm/11-approvals.jpg)

문서를 열어 요청자·사용 내역·합계·첨부와 결재 진행 단계를 확인합니다.

![PM 전자결재 상세](screenshots/pm/12-approval-detail.jpg)

### 설정

프로필과 회사 정보를 확인합니다. PM도 회사 정보와 다음 관리 항목에 접근할 수 있습니다.

![PM 설정 탭](screenshots/pm/13-settings.jpg)

연차·개인경비·재직증명서·도서 구입의 1차 PM·2차 관리자 승인선을 구성합니다.

![PM 승인선 설정](screenshots/pm/15-approvers.jpg)

사용자 역할·입사일·연차 기준일·활성 상태를 관리합니다. 캡처에는 가상 계정만 있습니다.

![PM 사용자 관리](screenshots/pm/16-users.jpg)

자동 알림과 외부 연동 설정을 확인합니다. 인증정보는 비워 두었고 알림·AI·동기화를 실행하지 않았습니다.

![PM 자동화와 연동 설정](screenshots/pm/17-automation.jpg)

CSV 내보내기와 대상·기간별 활동 로그 조회 영역입니다.

![PM 내보내기와 감사 로그](screenshots/pm/18-export-audit.jpg)

### 프로젝트 입력

담당자·업무 영역·상태·진행률·확인할 데이터·상세 내용을 입력합니다. 일정·체크리스트·첨부파일도 추가할 수 있습니다.

![PM 프로젝트 입력 양식](screenshots/pm/14-project-form.jpg)

## 관리자 전용 화면

다음 경영 홈은 **관리자 계정으로 캡처**했습니다. PM의 출퇴근·일정 홈과 섞어 기본 화면으로 소개하지 않습니다. 표시된 업무·인사·결재 내용은 가상 예시이며 매출·프로젝트 연동은 미설정 상태입니다.

![관리자 전용 경영 홈](screenshots/admin/01-executive-home.jpg)

### 관리자 최종 승인 단계

PM 승인 후 지정된 2차 관리자 승인자가 확인하는 문서입니다. 아래는 처리 대기 상태의 가상 문서이며 실제 승인·반려는 실행하지 않았습니다. 연차 총일수 변경이나 이력 일괄 처리는 권한 표로 구분하고 별도 실행 예시로 제공하지 않습니다.

![관리자 최종 승인 대기 문서](screenshots/admin/02-final-approval.jpg)

## 별도 CS 화면

CS는 일반 대시보드의 PM 탭이 아닙니다. 설치자가 별도 CS 인증과 상담·분석 소스를 설정해야 합니다.

### CS 지표

주간 상담 인입률·환불률·고유 구매자·추이를 확인하는 화면입니다. 원본 미연결 상태를 보여줍니다.

![별도 CS 지표](screenshots/cs/01-metrics.jpg)

### CS 상담일지

기간·유형별 검색과 해결률·재문의율·처리시간·상담 내역을 확인합니다. 상담 원문이나 고객 자료는 포함하지 않습니다.

![별도 CS 상담일지](screenshots/cs/02-consultations.jpg)
